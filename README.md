# RAGEB8 COMMUNICATION WEBPAGE!
-Utkarsh, Kamand Prompt Communication Webpage

This application was made using the MERN stack (MongoDB, Express, React, Node.js), Socket.io for live communication, and Vite + Tailwind CSS for a responsive dark themed interface.

## Tech Stack - 
### **Frontend**
* **React** (v18+) with functional hooks
* **Vite** for lightning-fast bundling and development
* **Socket.io-client** for real-time event handling
* **Tailwindcss** with custom variables, animations, and responsive flexbox layouts

### **Backend**
* **Node.js** & **Express.js** REST API server
* **Socket.io** for real-time bi-directional event communication (private messaging, group rooms, live message reactions)
* **MongoDB & Mongoose** for database management and chat history persistence


## Features - 
1. Sending text, voice messages and images to users on the same platform.
2. Creating a group chat with several members.
3. Message Reactions 
4. Responsive Design that changes on-screen elements based on the device's dimensions.
5. Authentication System that keeps messages private (both sent to another user or the LLM).
6. Integration with an LLM (Gemini) using Gemini API Key for communicating with it inside the webpage's interface.

-Please Note, .env files haven't been added to this repository for security purposes.
